# TextoForHA

Une application locale pour consulter et gérer les SMS de plusieurs modems,
avec des vues communes pour le réseau, la configuration et la carte SIM.

Huawei HiLink, modems série AT et intégrations HiLink2HA existantes.
Version bêta : les fonctions disponibles dépendent de la clé et de son firmware.

Ouvrir l’onglet Documentation pour l’installation, les connexions et les limites.
