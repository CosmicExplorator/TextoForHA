# Changelog

## 0.1.1

- Added a default modem option for automations.
- Added `POST /api/actions/send` for the default modem.
- Added configurable log level.
- Disabled legacy integration import by default.
- Added a short installation guide.

## 0.1.0 (02/10/2024)
- Première version publique.
- Support des modems **Huawei HiLink** (B535, B818, E3372).
- Support des modems **série AT** (Qualcomm, Wavecom).
- Interface web pour gérer les SMS (port 8099).
- Intégration avec l'API Home Assistant.
- Tests validés sur amd64.

## 0.0.1 (30/09/2024)
- Version bêta interne.
- Développement initial.
